# High-School Math Plan

## Goal

Transform the high-school mathematics curriculum into executable skills with
metadata, validation, formulas, explanations and reusable output contracts.

## Phase 1

- Numbers and fractions
- Prime numbers and divisibility
- Fibonacci, PA and PG
- First-degree equations
- Quadratic equations
- Quadratic vertex
- 2x2 linear systems
- Distance between points
- Central tendency

## Phase 2

- Affine and quadratic functions
- Function graphs and roots
- Exponents and logarithms
- Plane geometry
- Trigonometry in right triangles

## Phase 3

- Analytic geometry
- Probability
- Statistics
- Matrices and determinants

## Rule for each skill

Every new skill should define:

- `skill_id`
- inputs
- outputs
- formulas
- validation rules
- explanation steps
- tests

## First implementation candidates

- `functions.affine.root`
- `plane_geometry.triangle_area`
- `trigonometry.right_triangle_basic`
- `probability.simple_probability`
